The classic beginner problem — print numbers 1–100, replacing multiples of 3 with "Fizz" and multiples of 5 with "Buzz".

# Classic FizzBuzz for i in range(1, 101): if i % 15 == 0: print("FizzBuzz") elif i % 3 == 0: print("Fizz") elif i % 5 == 0: print("Buzz") else: print(i)

A basic calculator using a while loop and user input — great practice for conditionals.

# Simple calculator while True: a = float(input("First number: ")) op = input("Operator (+, -, *, /): ") b = float(input("Second number: ")) if op == "+": print(a + b) elif op == "-": print(a - b) elif op == "*": print(a * b) elif op == "/": print(a / b if b != 0 else "Error") else: print("Unknown operator")
club member

Pick a random number and give the user hints until they get it right.

import random secret = random.randint(1, 100) while True: guess = int(input("Guess (1-100): ")) if guess < secret: print("Too low!") elif guess > secret: print("Too high!") else: print("Correct!") break

Toggle dark mode with one click and save the preference to localStorage.

// Dark mode toggle const btn = document.getElementById('toggle'); btn.addEventListener('click', () => { document.body.classList.toggle('dark'); localStorage.setItem('theme', document.body.classList.contains('dark') ? 'dark' : 'light' ); });
